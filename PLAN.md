## 3. Решения

### Плеер: прямое окно VK вместо iframe (перенесено из тенниса)

- Проблема (со слов пользователя): в приложении видео не показывается — как было в теннисе.
- Проверено в теннисном проекте 14.11.2026: VK отказывает встроенному iframe на локальной
  странице `127.0.0.1`; iframe с no-referrer не помог; официальный `video_ext.php`,
  открытый как самостоятельная страница, эфир воспроизвёл. Точная серверная причина
  отказа iframe не доказана. В этом проекте отдельно не воспроизводилось.
- Решение: `src/web/app.js` `openPlayer` при наличии `window.mc` вызывает
  `mc.openPlayer(embed, title)` (preload.cjs → IPC `player:open`, только от главного окна);
  `src/electron/main.cjs` `openPlayerWindow` проверяет адрес VK (`https`, `vkvideo.ru|vk.com|vk.ru`,
  путь `/video_ext.php`), добавляет `autoplay`/`js_api`/`mute` и открывает свой `BrowserWindow`.
  В теннисе то же делается подменой `window.open('player.html?src=…')` — здесь упрощено
  по /simplify 14.11.2026: адрес плеера собирается в одном месте, `player.html` в приложении
  не участвует. Навигацию главного окна и окон плеера стережёт общий `guardNavigation`.
  Окно: 800×450 по содержимому, 16:9 (`aspect.cjs`), поверх окон, `sandbox`,
  `contextIsolation`, без `nodeIntegration`; чужие ссылки — во внешний браузер.
  Заголовок окна — «матч · канал», `<title>` VK его не перебивает (отличие от тенниса).
- `src/web/format.mjs` `embedUrl` больше не удаляет `__ref` — адрес VK передаётся как есть.
- Удалены: `did-create-window`, IPC `player:on-top` и кнопка «Поверх окон» в `player.html`,
  сообщение `to-tray` (в Electron плеера в строке нет — закрывать при уходе в трей нечего;
  окна плеера при этом остаются открытыми).
- Ограничение: в приложении нет плеера в строке, возврата записи из окна в строку с той же
  секунды и «⧉ В окне». Код для браузера (`player.html`, `player.js`, `opened.mjs`, iframe) —
  используемый, не удалять.

### Качество и звук (перенесено из тенниса без изменений)

- `src/electron/preload-player.cjs`: до скриптов VK пишет в localStorage
  `vk_player_preferred_default_quality_settings = {"type":"high_quality"}` один раз за запуск
  (метка `mc_default_quality_seeded`; сессия `matchcenter` живёт в памяти), чтобы ручной выбор
  в меню не перезаписывался следующими окнами. Публичный API VK качество менять не умеет;
  формат хранилища недокументирован — при его смене плеер вернётся к «Автоматически».
- `src/electron/player-audio.cjs`: первое окно — 50%, следующие при открытых — без звука;
  закрыли все — снова первое. `js_api=1`, self-postMessage `init → inited → set_volume →
  mute/unmute → volumechange`; до подтверждения звук окна выключен Electron, через 15 с
  без ответа API окно остаётся без звука. Ручные изменения потом не перезаписываются.

  браузер) — сейчас ранний выход `if (window.mc)`; повторная настройка звука при перезагрузке
  окна плеера (обработчики `dom-ready` живут до закрытия окна) — оставлено намеренно.
