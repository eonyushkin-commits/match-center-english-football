# Матч-центр | Английский футбол

Приложение для Windows: расписание английского футбола из FotMob (с русскими названиями и счётом)
и трансляции матчей из VK Видео. У каждого матча — кнопки каналов, по нажатию прямо под матчем
раскрывается плеер VK.

## Установка

Скачайте `match-center-<версия>-setup.exe` из раздела Releases и запустите. Ярлык — «Матч-центр».

## Как это работает

- **Расписание** берётся из FotMob, турниры и их порядок заданы в `config.json`.
- **Эфиры** читаются раз в `vkRefreshSeconds` секунд через API VK Видео — теми же запросами, которые
  делает страница `vkvideo.ru/@канал/lives` для незалогиненного посетителя (`vk-api.mjs`), все каналы
  примерно за секунду. Если API не ответил, канал читается по-старому: страница открывается в невидимом
  окне, и приложение забирает данные, которыми сайт наполняет свои карточки (`electron/preload-vk.cjs`).
  Аккаунт VK не нужен.
- **Привязка эфира к матчу** — по названиям команд в заголовке («Брайтон — Арсенал | АПЛ 5 тур»)
  и по времени создания эфира.

Читать каналы получается только с российского адреса: например, из Нидерландов те же страницы
приходят пустыми. Само видео идёт с вашего устройства напрямую в VK.

## Настройки

Правятся в `config.json`. У установленного приложения он лежит в папке пользователя, открыть её —
меню «Матч-центр» → «Открыть настройки». После правки перезапустите приложение.

Этот файл накладывается на встроенные настройки: каналы и алиасы из новых версий добавляются
к вашим сами, остальные поля берутся из вашего файла.

- `channels`: VK-каналы (`screenName` — часть ссылки после `@`, например `vkvideo.ru/@pl_forever`).
  Чтобы убрать встроенный канал, добавьте его с `"disabled": true`.
- `leagues`: какие турниры показывать и в каком порядке (ID FotMob): 47 — АПЛ, 48 — Чемпионшип,
  132 — Кубок Англии, 133 — Кубок английской лиги, 247 — Суперкубок Англии. ID виден в ссылке на лигу
  на fotmob.com (например, 42 — Лига чемпионов, 73 — Лига Европы, 74 — Суперкубок УЕФА).
- `teamAliases`: другие варианты написания команд, если канал пишет не так, как FotMob.
- `vkRefreshSeconds`: как часто перечитывать каналы.

## Разработка

```
npm install          # зависимости + Chromium для Playwright (нужен только для npm start)
npm run app          # запустить приложение
npm start            # то же самое без Electron: сервер на http://localhost:3777
npm run dist         # собрать установщик в dist/
```

Состав:

- `electron/main.cjs` — главный процесс: поднимает сервер, открывает окно, копирует настройки в папку пользователя.
- `electron/preload-vk.cjs` — перехват ответов на странице канала VK.
- `vk-api.mjs` — чтение каналов напрямую через API VK Видео (основной способ).
- `vk-electron.mjs` / `vk.mjs` — запасное чтение страницы канала: окном Electron и через Playwright
  (с `vkProxy` каналы читаются только через Playwright).
- `vk-parse.mjs` — общий разбор данных и фоновый опрос каналов.
- `server.mjs` — локальный сервер: страница и `/api/day` (расписание с привязанными эфирами),
  `/api/streams` — все прочитанные эфиры, для проверки.
- `match.mjs` — сопоставление заголовков эфиров с матчами.
- `public/index.html` — сам матч-центр: расписание, фильтры, встроенный плеер.
