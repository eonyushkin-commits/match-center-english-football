# Матч-центр | Английский футбол

Расписание английского футбола из FotMob с русскими названиями и счётом, а под каждым матчем —
трансляции из каналов VK Видео. Плеер раскрывается прямо под матчем.

## Установка

Скачайте `match-center-<версия>-setup.exe` из раздела Releases и запустите. Ярлык — «Матч-центр».
Дальше приложение обновляется само. Версия 2 ставится поверх первой и забирает её настройки.

## Что умеет

- **Сейчас в эфире** — отдельный блок сверху: матчи, которые идут и у которых есть живая трансляция.
- **Избранные команды** (★ рядом с названием): фильтр «Избранное» и уведомление Windows, когда
  начинается трансляция их матча. Клик по уведомлению открывает матч с плеером.
- **Состояние каналов**: кнопка «N эфиров» в шапке показывает каждый канал — прочитан ли, как
  (через API или страницу), сколько эфиров, когда обновлён, в чём ошибка.
- **Настройки в самом приложении** (кнопка ⚙ или «,»): каналы (добавить по ссылке, выключить,
  переименовать), турниры, частота обновления, уведомления, написание команд. Править JSON не нужно.
- **Горячие клавиши**: ← → — дни, / — поиск, R — обновить, Esc — закрыть плеер.
- **Автообновление** из GitHub Releases: новая версия скачивается сама и ставится при закрытии.
- Светлая и тёмная темы (по умолчанию — как в системе), узкое окно, окно открывается там, где его закрыли.

## Как это устроено

```
src/core/       ядро на чистом Node — одно и то же для приложения и для сервера
  settings.mjs    встроенные настройки + отличия пользователя, перенос из v1, защита от поломки файла
  vk-api.mjs      чтение каналов через API VK Видео (основной способ, ~1 с на все)
  streams.mjs     параллельный опрос каналов: у каждого свой статус, таймаут и запасной способ
  fotmob.mjs      расписание с кэшем; при сбое сети — последние данные, а не ошибка
  match.mjs       сопоставление заголовков эфиров с матчами
  day.mjs         расписание дня с привязанными эфирами
  watch.mjs       трансляции избранных команд → уведомления
  server.mjs      локальный HTTP: страница и /api (только 127.0.0.1, проверка Host, CSP)
src/electron/   приложение: окно, меню, уведомления, автообновление, запасное чтение страницы
src/server/     запасное чтение страницы через Playwright для `npm start` (если установлен)
src/web/        интерфейс без сборки и фреймворков: index.html, styles.css, app.js
test/           node:test — сопоставление на реальных заголовках, настройки, опрос, сервер
```

Настройки лежат в `%APPDATA%\Матч-центр\settings.json`, там хранятся только отличия от встроенных.
Поэтому каналы и алиасы из новых версий доходят до всех сами. `config.json` первой версии
при первом запуске переносится автоматически.

Читать каналы получается только с российского адреса. Само видео идёт с вашего устройства напрямую в VK.

## Разработка

```
npm install
npm test             # тесты
npm run app          # приложение (профиль «Матч-центр (разработка)», не мешает установленному)
npm start            # без Electron: http://127.0.0.1:3777 (HOST, PORT, MC_DATA, VK_PROXY — см. src/cli.mjs)
npm run icon         # пересобрать build/icon.png из src/web/icon.svg
npm run dist         # установщик и latest.yml в dist/
```

## Выпуск версии

1. Поднять `version` в `package.json`, закоммитить.
2. `npm run dist`.
3. Создать релиз `vX.Y.Z` на GitHub и приложить **три файла** из `dist/`:
   `match-center-X.Y.Z-setup.exe`, `match-center-X.Y.Z-setup.exe.blockmap` и `latest.yml`.
   Без `latest.yml` установленные приложения не узнают об обновлении.
