# Матч-центр (FotMob + VK Видео)

Расписание и счёт берутся из FotMob (с русскими названиями). К каждому матчу привязываются эфиры
из VK-каналов, перечисленных в `config.json`. Привязка идёт по названиям команд в заголовке эфира
(«Брайтон — Арсенал | АПЛ 5 тур | …») и по времени.

## Установка и запуск

```
npm install
npm start
```

Потом откройте http://localhost:3777. Можно просто дважды щёлкнуть `start.cmd`.

`npm install` ставит Playwright и скачивает Chromium (~150 МБ).

## Как читаются эфиры VK

Раз в `vkRefreshSeconds` секунд (по умолчанию 120) сервер открывает `vkvideo.ru/@канал/lives` в безголовом
Chromium, как обычный незалогиненный посетитель, и берёт данные, которые страница сама загружает для карточек:
заголовок, ссылку, статус эфира и время. Токены и аккаунт VK не нужны.

Если сверху горит красная точка или появилось сообщение об ошибке, скорее всего, VK поменял страницу.
Все прочитанные эфиры можно посмотреть на http://localhost:3777/api/streams.

Важно: читать каналы получается только с российского адреса. С хостинга в Нидерландах те же страницы
открываются пустыми — VK не отдаёт список видео. Для такого случая есть `vkProxy` в `config.json`
(или переменная окружения `VK_PROXY`), например `socks5://127.0.0.1:1080`: через него Chromium
будет читать каналы. Ещё есть `HOST=127.0.0.1` — чтобы приложение не слушало внешние адреса.

## Настройка — `config.json`

- `channels`: VK-каналы (`screenName` — это часть ссылки после `@`, например `vkvideo.ru/@pl_forever`).
  `"embed": false` — эфиры канала открываются на vkvideo.ru в новой вкладке, а не во встроенном плеере.
  Так стоит у «Английского Акцента» и «АПЛ Навсегда»: у них закрыто встраивание на сторонних сайтах.
  Новый плеер VK (флаг `video_embed_spa_bff_anon`) спрашивает `video.getEmbed`, получает ошибку 15
  `Access denied` и показывает «Видео недоступно»; старая версия плеера этот запрет не проверяет.
  Какая версия достанется, решает VK, поэтому ошибка выглядит плавающей.
- `leagues`: какие турниры показывать и в каком порядке (ID FotMob): 47 — АПЛ, 48 — Чемпионшип,
  132 — Кубок Англии, 133 — Кубок английской лиги, 247 — Суперкубок Англии. ID видно в ссылке на лигу на fotmob.com
  (например, 42 — Лига чемпионов, 73 — Лига Европы, 74 — Суперкубок УЕФА).
- `teamAliases`: дополнительные варианты названий, если канал пишет команду не так, как FotMob.
- `vkRefreshSeconds`: как часто перечитывать каналы.

После правки `config.json` перезапустите сервер.

## Из чего состоит

- `server.mjs` — HTTP-сервер: отдаёт страницу и `/api/day` (расписание с привязанными эфирами).
- `vk.mjs` — чтение эфиров с каналов VK через Playwright.
- `match.mjs` — сопоставление заголовков эфиров с матчами.
- `public/index.html` — сам матч-центр: расписание, фильтры, встроенный плеер.
