# Матч-центр | Английский футбол

<img src="build/icon.png" alt="" width="96">

Расписание английского футбола из FotMob и трансляции матчей из каналов VK Видео в одном окне.
Под каждым матчем — кнопки каналов; плеер VK раскрывается прямо под матчем.

Windows 10/11, x64. Работает без аккаунтов и токенов.

## Установка и обновления

Установщик — на [странице последней версии](https://github.com/eonyushkin-commits/match-center-english-football/releases/latest)
(`match-center-X.Y.Z-setup.exe`). Он не подписан, поэтому SmartScreen попросит подтверждения:
«Подробнее» → «Выполнить в любом случае». Ставится в профиль пользователя, права администратора не нужны.
Версия 2 ставится поверх первой и переносит её `config.json`.

**Обновления — в два шага.** Приложение проверяет GitHub Releases при запуске и раз в 6 часов.
Когда выходит новая версия, над расписанием появляется полоса «Доступна версия X.Y.Z» со ссылкой
«Что нового» и кнопкой **«Скачать»**; во время загрузки виден процент. Потом кнопка сменится на
**«Установить»** — приложение перезапустится уже новой версией. Полосу можно скрыть крестиком
на любом шаге — она вернётся, когда загрузка закончится, или при следующем запуске; скачанная,
но не установленная версия поставится сама при выходе. Проверить вручную — **Alt** →
«Матч-центр» → «Проверить обновления».

## Возможности

### Расписание

- **Восемь дней** — полоса дат от трёх дней назад до четырёх вперёд, листается и стрелками **←** **→**.
  В полночь «Сегодня» само переходит на новый день.
- **Турниры** по умолчанию: Премьер-лига, Чемпионшип, Кубок Англии, Кубок английской лиги,
  Суперкубок Англии. Любой другой турнир FotMob добавляется в настройках.
- **Русские названия** команд и турниров, логотипы клубов и лиг.
- **Счёт и минута** идущего матча обновляются сами (с задержкой до минуты), победитель выделен.
  Статус матча — так, как его отдаёт FotMob: `FT`, `HT`, `AET`, `Pen`.
- **Сейчас в эфире** — блок над расписанием (для сегодняшнего дня) с матчами, которые идут
  и у которых есть живая трансляция.
- **Фильтры** «С трансляцией», «Идут сейчас», «★ Избранное» и **поиск** по команде или турниру.
  Фильтры запоминаются. Матч с открытым плеером или подробностями фильтры не прячут.

### Трансляции

- **Каналы** по умолчанию: Английский Акцент, АПЛ Навсегда, Sportcast, ВЫШЛИ! Можно добавить
  любой канал VK Видео.
- **Метки**: **LIVE** — идёт сейчас, рядом число зрителей («· 1,2 тыс. смотрят»);
  **скоро** — запланирована; **запись** — закончилась.
- **Порядок**: идущие всегда впереди и по числу зрителей — первой стоит самая популярная,
  обычно самая стабильная; дальше запланированные, затем записи в порядке создания.
  Несколько эфиров одного канала нумеруются: «Sportcast», «Sportcast 2».
- Наведите на кнопку — увидите полный заголовок эфира. Если трансляций у матча нет —
  кнопка «Искать в VK». Резервный эфир, который так и не начался, у завершённого матча скрыт.

### Плеер

- **Раскрывается под матчем** и сам выравнивается по центру экрана. Другой канал того же
  матча включается без закрытия плеера. **Esc** или повторное нажатие закрывают его.
- **Не перезагружается** при обновлении расписания, смене фильтров и даже при сбое сети.
- «Открыть в VK ↗» или **Ctrl + клик** по каналу — трансляция в браузере.
- **В отдельном окне** — «⧉ В окне» над плеером. Окно поверх остальных (переключается кнопкой
  «Поверх окон» у его верхнего края), держит пропорции 16:9. Окон можно открыть сколько угодно —
  так смотрят несколько матчей сразу.

### События и составы

- «Подробнее» или клик по названиям команд раскрывают под матчем:
  **события** — голы с авторами и ассистентами (пенальти и автоголы отмечены), карточки, замены,
  счёт в перерыве и в конце; **составы** — схема, основа с номерами, тренер и запасные
  (раскрываются у обеих команд сразу).
- У идущего матча события показываются **с задержкой в минуту**: трансляция в VK отстаёт от
  реального времени, и так события её не обгоняют. Обновляются сами, пока панель открыта.

### Без спойлеров

- Кнопка «Без спойлеров» рядом с фильтрами прячет счёт, победителя и события — чтобы смотреть
  запись, не зная результата. Счёт одного матча открывается нажатием на **?**.
  Режим запоминается.

### Избранное и уведомления

- **★** рядом с командой — команда в избранном: напоминания обо всех её матчах.
- **🔔** под временем начала — напомнить об одном матче, даже если команды не в избранном.
  Отметка сама удаляется через сутки после матча.
- Матчи избранных команд и отмеченные матчи выделены жёлтой полосой слева и попадают в фильтр «★ Избранное».
- **Уведомления Windows** со звуком: **за 15 минут** до начала («Начало через 15 мин») и **в начале
  матча** («Матч начался · смотреть: Sportcast», если трансляция уже идёт). Клик по уведомлению
  открывает матч, а если трансляция идёт — сразу и плеер.

### Трей и автозапуск

- Закрытие окна **прячет приложение в трей** — уведомления продолжают приходить. Открыть —
  клик по значку, выйти — правой кнопкой → «Выход» или **Ctrl+Q**. Можно выключить в настройках.
- **Запуск вместе с Windows** (выключен по умолчанию) — приложение стартует свёрнутым в трей.

### Каналы и их состояние

- Кнопка «N эфиров» в шапке: по каждому каналу — прочитан ли, каким способом, сколько эфиров
  и когда обновлён, в чём ошибка. Кнопка «Обновить сейчас» перечитывает каналы сразу.
  Цвет точки: зелёный — все каналы прочитаны, жёлтый — часть, красный — ни один.

### Прочее

- Тема: как в системе, светлая или тёмная.
- Окно открывается там, где его закрыли, того же размера. Второй экземпляр приложения
  не запускается — показывается уже открытое окно. Версия — в заголовке окна.

| Клавиша | |
|---|---|
| **←** **→** | предыдущий / следующий день |
| **/** | поиск |
| **R** | обновить |
| **,** | настройки |
| **Esc** | закрыть плеер |
| **Ctrl + клик** по каналу | открыть трансляцию в браузере |
| **Ctrl+Q** | выйти из приложения |

## Настройки

Всё меняется в окне настроек (кнопка справа вверху или **,**):

- **каналы** — добавить по ссылке `vkvideo.ru/@name`, переименовать, выключить встроенный,
  удалить добавленный;
- **турниры** — отметить нужные или добавить любой другой по ID из ссылки `fotmob.com/leagues/ID/…`;
- **частота опроса каналов** — от 30 секунд до 5 минут;
- **уведомления**, **трей**, **запуск вместе с Windows**;
- **написание команд** — если канал пишет команду не так, как FotMob:
  `Манчестер Юнайтед = МЮ, Ман Юнайтед`.

Файл — `%APPDATA%\Матч-центр\settings.json` (**Alt** → «Матч-центр» → «Папка с настройками»).
В нём хранятся **только отличия** от встроенных настроек, поэтому каналы и варианты названий
из новых версий добавляются сами. Если правите руками — выйдите из приложения (из трея),
иначе оно перезапишет файл при следующем сохранении.

```json
{
  "channels": [
    { "screenName": "my_channel", "label": "Мой канал" },
    { "screenName": "pl_forever", "disabled": true }
  ],
  "leagues": [47, 48, 132, 133, 247, 42],
  "teamAliases": { "Манчестер Юнайтед": ["МЮ"] },
  "refreshSeconds": 120,
  "notifications": true,
  "tray": true,
  "autostart": false,
  "favorites": [{ "id": 8650, "name": "Ливерпуль" }],
  "favoriteMatches": [{ "id": 4813581, "name": "Фулхэм — Челси", "utcTime": "2026-10-18T14:00:00Z" }]
}
```

Сломанный файл не мешает запуску: приложение сохранит его копию рядом, запустится
с настройками по умолчанию и покажет предупреждение.

## Как это работает

**Каналы VK** читаются раз в минуту (настраивается) — все параллельно, около секунды на круг.
Приложение делает те же запросы к API VK Видео, что и сайт для незалогиненного посетителя:
анонимный токен → каталог «Трансляции» канала → две догрузки, это примерно месяц эфиров.
Если API не ответил, канал читается запасным способом — страница открывается в скрытом окне.
При ошибке у канала остаются последние прочитанные эфиры.

**Привязка трансляции к матчу** — по названиям команд в заголовке. Команды ищутся в любой
части заголовка между `|` («Брайтон — Арсенал | АПЛ 5 тур», «Смотреть онлайн АПЛ | Брайтон – Арсенал»),
лишние слова отсекаются, опечатки прощаются. Совпадение только по общим словам («Юнайтед»,
«Сити», «Манчестер») не засчитывается. Учитываются эфиры, созданные от пяти дней до матча
до шести часов после начала.

**Плеер** — официальный встраиваемый плеер VK. Сессия окна живёт только в памяти: если войти
в VK внутри плеера, после перезапуска вход забудется. Это сделано нарочно — залогиненному
пользователю VK часто отвечает «Видео недоступно» на встроенные трансляции.

**Сеть.** Приложение обращается только к FotMob (`www.fotmob.com`, `images.fotmob.com` —
расписание, события, составы), VK (`login.vk.ru`, `api.vkvideo.ru`, `vkvideo.ru`) и GitHub
(обновления). Никакой статистики не отправляет. Видео идёт с вашего компьютера напрямую в VK.
Внутри приложения работает локальный сервер только на `127.0.0.1` — из сети он недоступен.

**Россия.** VK отдаёт эти каналы только на российский IP. С VPN в другую страну трансляций не будет.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Трансляций нет, точка у «N эфиров» красная | Нужен российский IP — выключите VPN или смените страну |
| В плеере «Видео недоступно» | «Открыть в VK ↗» над плеером; если входили в VK в плеере — выйдите из приложения и откройте снова |
| Трансляция есть на канале, но не под матчем | Добавьте вариант названия команды в настройках; пока — «Искать в VK» |
| Нет уведомлений | Команда в ★ или матч отмечен 🔔, уведомления включены, в Windows выключен «Не беспокоить». Уведомления приходят, пока приложение запущено — окно может быть закрыто в трей |
| События матча «появятся через 60 с» | Так задумано: у идущего матча события идут с задержкой в минуту |

## Без установки: в браузере или на своём сервере

Нужен Node.js 22+. Electron для этого режима не нужен.

```
git clone https://github.com/eonyushkin-commits/match-center-english-football
cd match-center-english-football
npm install --omit=dev
npm start                       # http://127.0.0.1:3777
```

| Переменная | По умолчанию | |
|---|---|---|
| `PORT` | `3777` | порт |
| `HOST` | `127.0.0.1` | `0.0.0.0` — доступ из сети |
| `MC_DATA` | `./data` | где хранить `settings.json` |
| `VK_PROXY` | — | `socks5://host:port` — читать VK через прокси; нужен Playwright (`npm install playwright && npx playwright install chromium`) |

Учтите: в этом режиме настройки, избранное и тема общие для всех, кто открывает страницу,
а входа по паролю нет. Если открываете сервер в интернет, закройте его авторизацией на
уровне обратного прокси. Уведомлений, трея и обновления приложения в браузере нет;
«В окне» открывает плеер во всплывающем окне браузера.

Запуск приложения из исходников — `npm install` и `npm run app` (использует отдельный
профиль «Матч-центр (разработка)» и не мешает установленной версии).
