# Матч-центр | Английский футбол

<img src="build/icon.png" alt="" width="96">

Расписание английского футбола из FotMob и трансляции матчей из каналов VK Видео в одном окне.
Под каждым матчем — кнопки каналов; плеер VK раскрывается прямо под матчем.

Windows 10/11, x64. Работает без аккаунтов и токенов.

## Установка и обновления

Установщик — на [странице последней версии](https://github.com/eonyushkin-commits/match-center-english-football/releases/latest)
(`match-center-X.Y.Z-setup.exe`). Он не подписан, поэтому SmartScreen попросит подтверждения:
«Подробнее» → «Выполнить в любом случае». Ставится в профиль пользователя, права администратора не нужны.

Обновления ставятся сами: приложение проверяет GitHub Releases при запуске и раз в 6 часов,
скачивает новую версию в фоне и устанавливает при закрытии. Проверить вручную — **Alt** →
«Матч-центр» → «Проверить обновления».

Версия 2 ставится поверх первой и переносит её `config.json`.

## Что внутри

- **Расписание** — турниры из настроек, по умолчанию АПЛ, Чемпионшип, Кубок Англии,
  Кубок лиги и Суперкубок. Счёт и минута матча обновляются сами, с задержкой до минуты; статус матча
  показывается так, как его отдаёт FotMob (`FT`, `HT`, `AET`, `Pen`).
- **Трансляции** — встроенные каналы: Английский Акцент, АПЛ Навсегда, Sportcast, ВЫШЛИ!
  Можно добавить любой канал VK Видео. У каждой трансляции метка:
  **LIVE** (идёт, рядом — сколько смотрят), **скоро** (запланирована), **запись**.
  Идущие всегда впереди и отсортированы по числу зрителей, записи — по времени создания.
- **Сейчас в эфире** — блок над расписанием с матчами, которые идут и у которых есть живая трансляция.
- **Избранные команды** (★ у названия) — фильтр и уведомление Windows, когда начинается
  трансляция их матча. Клик по уведомлению открывает матч с плеером.
- **Состояние каналов** — кнопка «N эфиров»: по каждому каналу видно, прочитан ли он, каким
  способом, сколько эфиров и когда. Цвет точки: зелёный — все каналы прочитаны, жёлтый — часть, красный — ни один.
- Светлая/тёмная тема (или как в системе), фильтры, поиск; окно запоминает размер и положение.

| Клавиша | |
|---|---|
| **←** **→** | предыдущий / следующий день |
| **/** | поиск |
| **R** | обновить |
| **,** | настройки |
| **Esc** | закрыть плеер |
| **Ctrl + клик** по каналу | открыть трансляцию в браузере |

## Как это работает

**Каналы VK** читаются раз в минуту (настраивается от 30 с до 5 мин) — все параллельно, около
секунды на круг. Приложение делает те же запросы к API VK Видео, что и сайт для незалогиненного
посетителя: анонимный токен → каталог «Трансляции» канала → две догрузки, это примерно месяц
эфиров. Если API не ответил, канал читается запасным способом — страница открывается в скрытом окне.
При ошибке у канала остаются последние прочитанные эфиры.

**Привязка трансляции к матчу** — по названиям команд в заголовке. Команды ищутся в любой
части заголовка между `|` («Брайтон — Арсенал | АПЛ 5 тур», «Смотреть онлайн АПЛ | Брайтон – Арсенал»),
лишние слова отсекаются, опечатки прощаются. Совпадение только по общим словам («Юнайтед»,
«Сити», «Манчестер») не засчитывается. Учитываются эфиры, созданные от пяти дней до матча
до шести часов после начала. Запланированный, но так и не начавшийся эфир у завершённого
матча («РЕЗЕРВ. …») скрывается.

**Плеер** — официальный встраиваемый плеер VK. Сессия окна живёт только в памяти: если войти
в VK внутри плеера, после перезапуска вход забудется. Это сделано нарочно — залогиненному
пользователю VK часто отвечает «Видео недоступно» на встроенные трансляции.

**Сеть.** Приложение обращается только к FotMob (`www.fotmob.com`, `images.fotmob.com`),
VK (`login.vk.ru`, `api.vkvideo.ru`, `vkvideo.ru`) и GitHub (обновления). Никакой статистики
не отправляет. Видео идёт с вашего компьютера напрямую в VK. Внутри приложения работает
локальный сервер только на `127.0.0.1` — из сети он недоступен.

**Россия.** VK отдаёт эти каналы только на российский IP. С VPN в другую страну трансляций не будет.

## Настройки

Всё меняется в окне настроек (кнопка справа вверху или **,**): каналы (добавить по ссылке
`vkvideo.ru/@name`, выключить, переименовать), турниры (плюс любой другой по ID из ссылки
`fotmob.com/leagues/ID/…`), частота опроса каналов, уведомления и варианты написания команд.

Файл — `%APPDATA%\Матч-центр\settings.json` (**Alt** → «Матч-центр» → «Папка с настройками»).
В нём хранятся **только отличия** от встроенных настроек, поэтому каналы и варианты названий
из новых версий добавляются сами. Если правите руками — закройте приложение, иначе оно
перезапишет файл при следующем сохранении.

```json
{
  "channels": [
    { "screenName": "my_channel", "label": "Мой канал" },
    { "screenName": "pl_forever", "disabled": true }
  ],
  "leagues": [47, 48, 132, 133, 247, 42],
  "teamAliases": { "Манчестер Юнайтед": ["МЮ"] },
  "refreshSeconds": 120,
  "notifications": true,
  "favorites": [{ "id": 8650, "name": "Ливерпуль" }]
}
```

`teamAliases` — если канал пишет команду не так, как FotMob: слева название из расписания,
справа варианты из заголовков. Сломанный файл не мешает запуску: приложение сохранит его копию
рядом, запустится с настройками по умолчанию и покажет предупреждение.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Трансляций нет, точка у «N эфиров» красная | Нужен российский IP — выключите VPN или смените страну |
| В плеере «Видео недоступно» | «Открыть в VK ↗» над плеером; если входили в VK в плеере — перезапустите приложение |
| Трансляция есть на канале, но не под матчем | Добавьте вариант названия команды в настройках; пока — «Искать в VK» |
| Нет уведомлений | Команда в ★, уведомления включены, в Windows выключен «Не беспокоить». Уведомляется только эфир, начавшийся при открытом приложении |

## Без установки: в браузере или на своём сервере

Нужен Node.js 22+. Electron для этого режима не нужен.

```
git clone https://github.com/eonyushkin-commits/match-center-english-football
cd match-center-english-football
npm install --omit=dev
npm start                       # http://127.0.0.1:3777
```

| Переменная | По умолчанию | |
|---|---|---|
| `PORT` | `3777` | порт |
| `HOST` | `127.0.0.1` | `0.0.0.0` — доступ из сети |
| `MC_DATA` | `./data` | где хранить `settings.json` |
| `VK_PROXY` | — | `socks5://host:port` — читать VK через прокси; нужен Playwright (`npm install playwright && npx playwright install chromium`) |

Учтите: в этом режиме настройки, избранное и тема общие для всех, кто открывает страницу,
а входа по паролю нет. Если открываете сервер в интернет, закройте его авторизацией на
уровне обратного прокси. Уведомлений о трансляциях в браузере нет.

Запуск приложения из исходников — `npm install` и `npm run app` (использует отдельный
профиль «Матч-центр (разработка)» и не мешает установленной версии).
